# Response Style (always loaded)

How to answer in chat. Docs, commits and site copy are `writing.md`.

- Be concise. Answer first; no preamble, no restating the question, no recap at the end.
- No hedging filler: "it's worth noting", "it's important to", "keep in mind".
- Ask questions and offer choices with `AskUserQuestion`, recommended option first, never as a
  trailing question in prose.
- A loose end you noticed and are not doing is a question too. If it is in scope, cheap and
  reversible, do it and say so instead.
- Plain prose over bullets unless the content needs structure. Draw data flows as inline
  diagrams in the terminal.
- Reporting a problem: problem (one line), why (the mechanism), effect (what the user sees),
  risk (what is at stake if it ships).
- Say which "done" you mean and which gates ran.
